# Matched-Lap Extractor Phase 4 Smoke Results

Date: 2026-05-13
Status: local-cache smoke validation passed

This file records the first smoke run of the Phase 3 matched-lap extractor
against the five locked sessions from
`docs/fixes/matched_lap_extractor_smoke_sessions.md`.

The run used local FastF1 cache only:

```text
data/raw/.fastf1_cache
```

Reusable evidence was generated by:

```text
scripts/validate_matched_lap_smoke_sessions.py
```

Output files live under:

```text
data/diagnostics/matched_lap_extractor_smoke/
```

The extractor was not tuned to force these outputs. Two expectation
mismatches are documented below because the locked smoke doc was slightly
more optimistic than the real extractable evidence.

- Output rows: 257 `matched_pair`, 1 `skipped_pair`.

### Representative Qualifying

- Event: 2024 Bahrain Grand Prix, Qualifying.
- Output rows: 28 `matched_pair`, 2 `skipped_pair`.

- Skip reasons: 2 `insufficient_matched_pairs`.
- Filter totals: 0 non-green laps, 0 SC/VSC laps, 182 pit laps,

- Team notes:

  `no_common_quali_segment` row appears. The Q1-only branch is visible as an
  insufficient-sample branch, not as accepted evidence.
